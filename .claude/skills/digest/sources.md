# Digest sources

The digest skill opens every source below on each run. Keep one `- [Name](url): note` line per source under one of the four topic headings. Sources that cover several topics sit under the topic where most of their items land; their note says to scan for all topics.

## Models

- [Anthropic news](https://www.anthropic.com/news): model and product announcements
- [OpenAI news](https://openai.com/news/): model and product announcements
- [Google DeepMind blog](https://deepmind.google/discover/blog/): listing is not strictly by date, open each post
- [Meta AI blog](https://ai.meta.com/blog/): Llama and research announcements
- [Mistral AI news](https://mistral.ai/news): model releases
- [xAI news](https://x.ai/news): Grok model releases
- [DeepSeek API change log](https://api-docs.deepseek.com/updates): model and API updates
- [Hugging Face blog](https://huggingface.co/blog): open model releases and guides
